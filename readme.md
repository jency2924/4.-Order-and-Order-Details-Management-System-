
# Week 4 – Order and Order Details Management System

## Project Overview
This project focuses on managing and analyzing customer orders in an e-commerce database using MySQL. It uses the existing `ecommerceD__B` database and performs different SQL operations on the Orders and Order_Details tables.

## Database Tables
The database contains the following tables:
- Customer
- Category
- Product
- Seller
- Inventory
- Orders
- Order_Details

## Objectives
- Retrieve customer order information.
- Display products included in each order.
- Calculate total items and order amounts.
- Analyze customer-wise spending.
- Generate product-wise sales reports.
- Summarize orders based on their status.

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- INNER JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- COALESCE()
- CASE

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## How to Execute
1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Open the Week4_Order_Management.sql file.
4. Select the existing ecommerceD__B database.
5. Execute the queries one by one.
6. View the results in the Result Grid.

## Expected Outcome
The queries generate order reports, customer spending summaries, product sales reports, and order status summaries.

## Conclusion
This project demonstrates how SQL queries can be used to manage and analyze e-commerce order information effectively.
